# Glosario

Ver tambien: [[Arquitectura]], [[Flujos Importantes]]

- **TerriaJS**: libreria geoespacial de este repositorio.
- **TerriaMap**: aplicacion/shell que consume TerriaJS y suele ser el punto de despliegue final.
- **TerriaJS-Server**: servidor Node que sirve assets, proxy, share service y rutas auxiliares.
- **Terria**: clase raiz del estado de aplicacion.
- **InitSource**: fuente de inicializacion aplicada al arrancar una instancia de Terria.
- **Traits**: definicion tipada de propiedades configurables.
- **Strata**: orden de precedencia de valores de traits.
- **Catalog member**: entidad del catalogo; puede ser item, group, reference o function.
- **Workbench**: conjunto de items activos/visibles.
- **ViewState**: estado de UI de alto nivel.
- **TerriaViewer**: orquestador del viewer y del cambio 2D/3D.
- **CatalogIndex**: indice opcional para busqueda y localizacion de miembros de catalogo.
- **ShareDataService**: servicio para acortar/resolver share URLs.
- **CORS proxy**: proxy usado para acceder a servicios geoespaciales que no exponen CORS.
