# Vault de Obsidian

Esta vault resume el repositorio para onboarding, mantenimiento y trabajo asistido por herramientas.

Empieza por [[Index]].

## Alcance

- Documentacion sintetica para humanos sobre este repo.
- No reemplaza `doc/` ni `architecture/`; esas carpetas siguen siendo material fuente importante.
- Prioriza hechos verificables del codigo y de la configuracion actual del repositorio.

## Convenciones

- Usar wikilinks `[[...]]` entre notas.
- Mantener nombres de notas simples y estables.
- Si algo no esta confirmado en el repo: `Pendiente por confirmar`.
- Si algo es una deduccion razonable pero no explicita: `Inferencia`.

## Mantenimiento

Cuando cambien arquitectura, comandos, configuracion, variables de entorno, testing o despliegue, actualizar la nota correspondiente y revisar [[Index]].
