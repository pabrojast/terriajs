## Chart.js opt-in renderer for CSV time-series (TerriaJS)

- **Charts are Visx (`@visx/*`) + D3**, SVG-based. The opt-in Chart.js renderer is an ADDITION, gated so the legacy path stays byte-identical when off.
- **Switch mechanism**: trait `useChartJsTimeSeries` (default false) + `chartJsShowDataTable` (default true) on `CsvCatalogItemTraits`. `lib/Table/tableFeatureInfoContext.ts` emits `renderer="chartjs"` on the `<chart>` tag when the CSV item has the trait on; `ChartCustomComponent.processChart` branches on `attrs.renderer === "chartjs"`. `renderer`/`show-data-table` must be in `ChartAttributes` or they get stripped by the HTML sanitizer.
- **Lazy isolation is a hard invariant**: only `lib/ReactViews/Custom/Chart/ChartJs/registerChartJs.ts` and `ChartJsLineChart.tsx` may statically import the chart.js RUNTIME (`chart.js`, `react-chartjs-2`, `chartjs-plugin-zoom`, `chartjs-adapter-moment`). Everything else reaches it via `React.lazy(() => import("./ChartJsLineChart"))`. Light files may use `import type` (erased). Date adapter = `chartjs-adapter-moment` (moment already a dep; do NOT add date-fns).
- **CRITICAL runtime gotcha**: the `<chart>` custom component hands the renderer a freshly-constructed, DISCONNECTED `CsvCatalogItem` (only `csvString` set). `TableMixin.chartItems` returns `[]` until `loadMapItems()` (async) runs. Any feature-info chart component MUST trigger `item.loadMapItems()` in a `useEffect` and show a loading state while `item.isLoadingMapItems` — exactly like `lib/ReactViews/Custom/Chart/FeatureInfoPanelChart.tsx`. Forgetting this = permanent "No chart data".
- **CSV export**: apply the formula-injection guard (`=+-@`/tab/CR → prefix `'`) ONLY to string cells; numbers (incl. negatives) must pass through, else `-5` becomes `'-5`.
- **Project build/test**: lockfile is `yarn.lock` (tracked; `package-lock.json` is gitignored) — install deps with `yarn` to avoid huge npm re-sort churn. `npm install` needs `--legacy-peer-deps` (pre-existing pretty-quick/prettier@2 conflict). Fast strong verify = `tsc --noEmit -p tsconfig-node.json` (incremental, lib-only, ~35s cold; covers .tsx). Full unit tests run via Karma (heavy).
